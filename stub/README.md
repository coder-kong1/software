# 智能充电桩系统测试桩

测试桩用于验收展示时模拟多个客户端和管理员操作，不需要准备多台电脑。

## 启动方式

```bash
cd stub
npm run dev
```

默认访问地址：

```text
http://localhost:5175
```

如果要让同一局域网下其他设备访问，使用 Vite 输出的 Network 地址，例如：

```text
http://本机局域网IP:5175
```

## 前置条件

- 后端服务已启动在 `http://localhost:8080`
- 测试桩通过 Vite 代理访问 `/api`，不需要额外修改后端 CORS

## 覆盖场景

- 批量准备测试车辆
- 时间顺序调度
- 优先级调度
- 充电桩故障、恢复、重新调度
- 开始充电、结束充电、账单生成、支付
- 异常事件登记和处理
- 查询指定充电桩队列
- 手工提交车辆申请、修改电量、修改模式、控制充电过程

## 使用建议

验收展示前可以把“测试车前缀”改成一个新的字母，例如 `T`、`D`、`X`，避免和已有演示数据冲突。
